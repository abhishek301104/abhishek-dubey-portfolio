# Abhishek Kumar Dubey — Developer Portfolio

A responsive personal portfolio highlighting projects in attendance analytics, vehicle tracking, and Retrieval-Augmented Generation (RAG).

## Run locally

This version uses plain HTML, CSS, and JavaScript, so it does not require a build tool.

1. Download or clone this repository.
2. Keep `index.html`, `styles.css`, `script.js`, and the `assets/` folder together.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Publish on GitHub Pages

1. Create a repository named `abhishek-dubey-portfolio`.
2. Upload all files and folders in this project.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site.
